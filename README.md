# 拾账 · 独立 PWA 设计预览

参考 [Subfolio 的 App Store 页面](https://apps.apple.com/us/app/subfolio-track-your-subs/id6829737968) 的四页布局，以原创网页实现浅灰紫背景、大圆角卡片、叠放账户卡及支持拖动切换的玻璃质感导航。首页替换为个人记账。图标由 SVG 绘制，未使用原应用图片资源。

## 本地使用

```sh
npm install
npm run dev
```

- 正常账本：http://localhost:4174/
- 示例体验：http://localhost:4174/?demo=1
- 构建与离线预览：`npm run build && npm run preview`
- 浏览器测试：`npm test`（使用电脑安装的 Google Chrome）

示例账本只在内存中运行；刷新会恢复示例数据，退出示例会回到自己的账本。正式账本使用独立 IndexedDB `shizhang-glass-v1`。没有读取或修改轻账的数据、源代码或部署。

## 当前功能

- 记账：支出、收入、退款、账户转账，账户余额及最近记录。
- 流水：月份筛选、文字搜索、类型筛选、日支出曲线。
- 账单：收支统计、不同周期图表、分类和账户支出、金额倒序分类明细、月度总预算。
- 设置：账户新增与编辑、分类新增与删除、亮色/深色/跟随系统、账本命名。
- 账单新增、编辑、删除；嵌套详情可返回原列表。
- 完整 JSON 导入导出（兼容轻账备份及带密码的轻账备份）、CSV 导出。
- 粘贴截图识别文字，本地规则解析；可自行配置 DeepSeek API。调用前会提示文字与分类将发送到 DeepSeek，密钥只保存在本地。示例模式不调用 AI 服务。
- 构建版本支持 Service Worker 离线访问。进入设置自动联网检查版本；新版本下载后点击“立即更新”，保留本地账本。

## 预览范围

独立试用网址：https://miaodidi.github.io/shizhang/ 。使用 iPhone Safari 打开后，点击分享 → 添加到主屏幕。主分支推送后由 GitHub Actions 自动构建并发布 GitHub Pages。玻璃效果是 CSS 实现，不是系统原生 Liquid Glass。图片 OCR 需要先在系统中完成；未提供云同步、原生 Android 能力、定期账单自动执行或订阅付费。

导入备份会在确认后替换拾账现有账本，不会影响轻账。浏览器存储可能被系统清理，请定期导出备份。支持备份中的周期规则数据保留，但本预览不自动执行它们。
